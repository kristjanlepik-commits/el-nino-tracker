## IN ENGLISH, for reference

Hello,

I am writing with a data request.

We are building a public, data-based climate overview that compares European
cities' summer temperatures against each city's own historical record. It
currently covers 24 cities across seven countries, using each national
weather service's open data. We would like to add Tallinn.

**What we are asking for:**

- Station: Tallinn-Harku (WMO 26038)
- Variables: daily minimum and maximum air temperature
- Period: the full available record, **particularly the years before 1991**
- Format: CSV or any machine-readable file

Your website provides daily data from 1991 onwards. Our method needs a
longer series: we use 1971-2000 as the reference period, because every other
city in the overview uses the same one. Without the earlier years, Tallinn
could not be compared with the others on the same basis.

**Two questions about terms of use:**

1. May we publish figures derived from this data (for example, the number of
   warm nights per year) on a public website?
2. May the project be commercial in nature, for instance if the publication
   has a sponsor? We would like to establish this before using the data.

We will always cite Keskkonnaagentuur as the source.

If providing the data carries a fee or requires a separate application,
please let me know how to proceed.

With thanks,
Kristjan Lepik

## Miks küsime just neid asju / Why these specifics

**Jaam WMO 26038.** See on täpselt sama jaam, mille ajaloolist rida hoiab
GHCN-Daily kuni 2025. aasta augustini, ja sama jaam, mida me praegu tunnis
korra üles kirjutame. Üks termomeeter, mitte kolm eri allikat kokku pandud.

**Aastad enne 1991 on kogu päringu mõte.** 1991-2020 rida on meil juba
kättesaadav ja sellest piisab standardhälbe arvutamiseks. Aga läviväärtused
arvutame perioodist 1971-2000, ja see on ainus asi, mida praegu kuskilt
võtta ei ole.

**Kasutustingimuste küsimus on tõsine, mitte formaalsus.** Me eemaldasime
sellel nädalal kogu ECA&D andmestiku, sest see on mitteäriline. Parem küsida
enne kui pärast.

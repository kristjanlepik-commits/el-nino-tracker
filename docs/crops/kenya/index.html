A fourth instrument is not shown here and it disagrees with these three. Cumulative vegetation, the crop-outcome measure closest to yield, reads 20th of 26 for this country with no region at a record. It integrates from the start of the season, so it is structurally the last to move and reads calmest exactly when a fast deterioration is under way. It is left off the panels because it is close to normal, so it renders almost blank, and an empty map looks like a missing one. Stated here rather than dropped silently, since without it these panels look worse than the full picture.

Hot here means 33.0 °C or above, a level about one summer day in twenty used to reach at this station between 1978 and 2000. That window is 23 of the 30 years every other city's threshold uses, because this thermometer only starts in 1978, so the level is set from its warmer years and sits a little high. The count below is an undercount rather than an overcount. The bar has not moved; the number of days clearing it has. Every year is counted to 3 August, so a part-finished summer is never set against complete ones. That threshold is Palma's own. It is not a national standard and it is not comparable with another city's: every figure on this page is measured against this station and nothing else.

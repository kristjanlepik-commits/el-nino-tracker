Hot here means 28.7 °C or above, a level about one summer day in twenty used to reach at this station between 1971 and 2000. The bar has not moved; the number of days clearing it has. Every year is counted to 7 August, so a part-finished summer is never set against complete ones. That threshold is Amsterdam's own. It is not a national standard and it is not comparable with another city's: every figure on this page is measured against this station and nothing else.

3 nights so far that never dropped below 20 °C. No multiple is quoted here. Amsterdam did not record a single one in the whole of 1961-1990 by this date, so there is no base to divide by. 19 of the 36 cities are gated this way.
